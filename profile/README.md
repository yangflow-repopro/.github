# yangflow

We build desktop applications, self-hosted services and tools for software development.
Our projects also include automation pipelines, product websites and shared libraries.

## How we work

We prefer simple solutions, clear boundaries and changes that can be verified.
Projects share a small set of collaboration and security rules, then choose the guidance that fits their
languages, platforms and deployment needs.

## Shared resources

- [Handbook](https://github.com/yangflow-repopro/.github/tree/main/handbook): core rules, practical guides and stack conventions.
- [Documentation templates](https://github.com/yangflow-repopro/.github/tree/main/handbook/templates): starting points for project documents.
- [Security reporting](https://github.com/yangflow-repopro/.github/blob/main/SECURITY.md): where to report a vulnerability privately.
