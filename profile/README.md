# yangflow-repopro

Native macOS menu bar apps, built with SwiftUI and Swift 6, shipped from their own websites.

| Product | What it does |
|---|---|
| [BareKeep](https://barekeep.com) | Keeps a private, always-fresh local mirror of your Git repositories, with optional off-site backup |
| [Loggia](https://useloggia.com) | Publishes a local port as a public HTTPS domain through Cloudflare Tunnel and shows whether the link is alive |

How we build: [handbook](https://github.com/yangflow-repopro/.github/tree/main/handbook).
Security reports: [SECURITY.md](https://github.com/yangflow-repopro/.github/blob/main/SECURITY.md).
