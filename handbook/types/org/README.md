# Repository type: org

This is the organization defaults documentation preset. Select only the stacks and components the project uses;
record its actual architecture and preset differences in its agent instructions and process document.

## What it is

The organization's `.github` repository: the handbook, the templates, the shared labels, issue and PR templates and
the reusable workflows. Public, so GitHub applies its defaults to every repository. `.repo-type` is `org`.

## Stacks

`handbook/stacks/python.md` for `scripts/`.

## Pages

[The handbook index](../../README.md) lists everything here.

## Templates

`handbook/templates/org/README.md` and the shared ones in `handbook/templates/common/`.

## Workflows

It defines the reusable workflows; it runs `docs.yml` on itself.
